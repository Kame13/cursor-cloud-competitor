- **调研日期**：2026-10-15
- **环境**：https://oms.xlwms.com （已登录现网）。帮助中心对照：https://help.xlwms.com/d458/fcbb/7023/ac24
- **账号**：测试号已登录。页眉客户标识已打码，笔记不写账号、仓库名、SKU、箱类型号。

现网已按「按产品出库 + 产品换标」建出一张单，并提交到仓库。第 9 节是第一次被「请先选择至少一件产品」拦住的过程。第 10 节是补上产品可用库存之后的保存和提交。第 3–6 节仍是帮助中心配图，和现网不一致时以第 9、10 节为准。

## 1. 功能目标（观察）

* **角色**：OMS 卖家（帮助正文称为在 OMS 向海外仓发出库指令的一方）
* **要解决的事**：把仓内已有库存做成备货中转出库。创建方式分「按产品出库」和「按箱出库」。按产品时只能做产品换标；勾选产品换标后，要为出库产品填写新条码 / 新标文件。

## 2. 入口与导航

* **现网菜单**：首页左侧「仓储服务」展开后为：入库、一件代发出库、备货中转出库、入库认领、次品处理、工单。列表 URL：`/warehouse/outboundOrder`。证据：`screenshots/18-oms-live-list.png`
* **登录页**（登录前）：账号名、密码、自动登录、忘记密码。证据：`screenshots/01-oms-login.png`
* **列表按钮**：新建、提交、导入、导出、获取面单；另有「自动提交已获取面单和无需面单的出库单」勾选。证据：`screenshots/02-oms-list.png`、`screenshots/07-oms-draft-actions.png`

## 3. 主流程

1. 登录 OMS（本次停在登录页）。
2. 仓储服务 → 备货中转出库 → 新建。
3. 基础信息：仓库、目的地类型、出库方式、是否换标、物流渠道等（红星为必填）。出库方式单选，一张单只能按产品或按箱。
4. 收件信息：手填，或从地址簿带入。
5. 出库方式 = 按产品：选择产品，填出库数量（正文：不得大于可用库存）。
6. 若勾选产品换标：在「换标服务 / 产品换标」里选已出库的产品，填换标数量、新条码，可上传新标文件，也可「添加新标」让一款旧产品对应多条新标。
7. 按需加增值服务、附件。目的地为 FBA 时正文要求必须上传箱唛。
8. 保存草稿。物流为「无需物流服务」或「上传物流面单」时，草稿落在「待提交」，再点提交，进入「仓库处理中」。物流为仓库渠道时，草稿落在「待获取面单」，先获取面单再提交。

## 5. 状态与 Tab（如有）

| **状态/Tab** | **含义（观察）** |
|---|---|
| 全部 | 所有备货中转出库单 |
| 草稿 · 待获取面单 | 已保存，还要获取物流面单 |
| 草稿 · 获取中 | 正在向打单系统要面单 |
| 草稿 · 待提交 | 无需面单，或已满足提交条件，还没交给仓库 |
| 草稿 · 获取异常 | 物流下单成功但面单获取失败 |
| 仓库处理中 | 已提交，仓库拣货、打包等 |
| 已出库 | 仓库完成出库 |
| 已取消 | 单据被终止 |
| 异常 | 提交或仓库处理中出现问题待处理 |

物流与按钮的对应（帮助正文）：

* 无需物流服务，或上传物流面单渠道：在「草稿-待提交」点提交 → 仓库处理中。
* 仓库渠道：在「草稿-待获取面单」点获取面单 → 获取中 → 再提交 → 仓库处理中。

## 6. 边界与提示（仅文案级）

* 出库方式不能混用。
* 按产品出库只允许产品换标；按箱出库才允许产品换标 + 箱换标。
* 出库数量不得大于可用库存。
* 未上传新标文件也可以提交。
* FBA 目的地必须上传箱唛。
* 常见问题：OMS 不能填写托盘数量（与创建页上可见的「出库托盘数」并存，见未确认）。
* 批量导入有两个模板：模板 1 一行一单、多产品横向填；模板 2 多行一单、多产品纵向填。黄色字段为必填。本次未展开模板列。
* 仓库处理中可截单；未取消成功时正文建议联系海外仓。

## 10. 补库存之后建成并提交（2026-10-15）

产品可用库存为 0 时，选择产品是 0 条。WMS「库存调整」「盘点 → 添加产品」同样是 0 条；库存调整页写着「仅支持调整产生过库存流水的库存」。这次走的是库内 → 产品库存 → 按库位查询 → 导入 → **库存初始化导入**（页面上没有名为「盘盈」的按钮）。模板列：客户代码、SKU、库存属性、库位编码、库存数、上架日期等。导入正品、数量 5，落在仓内已有库位。任务中心该导入为已完成。刷新产品库存：总库存 5、可用 5、锁定 0。

回到 OMS 创建页（按产品出库、产品换标仍勾着，物流渠道仍是无需物流服务）。目的地从默认的 FBA 改成「其他」，避免再被箱唛卡住。选择产品出现 1 条，可用库存 5。出库数量填 1。换标区点「添加产品」带出同一行，换标数量已等于出库数量，新条码填了测试值，新标文件没传。

保存草稿后，列表草稿子状态是待提交。行上点提交，确认框文案「确认提交吗？」。提交后草稿变为 0，仓库处理中多 1 条。这一条是：产品数量 1、目的地类型其他、出库方式按产品出库、物流渠道无需物流服务。提交后再刷 WMS 产品库存：总库存 5、可用 4、锁定 1。

没有点 WMS 的「提交拣货」。单号、SKU、客户代码不写入笔记。
