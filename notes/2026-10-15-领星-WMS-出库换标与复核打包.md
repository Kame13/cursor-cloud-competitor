## 1. 功能目标（观察）

* **角色**：仓库端操作员
* **要解决的事**：
  * 换标：OMS 已预报新旧标关系后，仓库扫旧标打新标，再回填实际换标数量。
  * 复核 / 打包：一件代发波次在「复核/验货」扫条码，可同时绑包材、称重、打面单；多包裹用「包裹复核」。备货中转大货的扫码复核在 PDA「复核出库」，且只处理待出库单据。

## 3. 主流程

### 3.1 备货中转（与 OMS 按产品 + 产品换标衔接）

帮助配图流程见 `screenshots/08-wms-bst-flow.png`。

1. 待处理：可按收件人、期望到仓时间、换标情况筛选，然后提交拣货。
2. 待拣货：打印拣货单（单张 / 分拣 / 汇总），或 PDA「拣货 → 大货拣货」。电脑端可填已拣数量和库位，也支持按推荐库位批量拣货。拣货单上用 Label Replace 标是否换标（正文：`-` 不换；`SKU` 产品换标；`Box` 箱换标；`Box+SKU` 两者都换）。需要产品换标时，打印拣货单会加打换标单。
3. 待出库 · 换标：筛出要换标的单，可打印换标单或下载新标文件；扫描作业在「出库 → 换标」。做完后在待出库「编辑换标服务」填实际换标数量。
4. 待出库 · 装箱（仅按产品出库）：填装箱明细，才能再填托盘明细。按箱出库则在待出库操作里填托盘明细。装箱 / 托盘会同步回 OMS。
5. 待出库 · 附件、面单、增值服务，然后确认出库（可批量）。
6. 出库前若要扫面单和箱唛复核：正文指向 PDA「复核出库」，只允许待出库的备货中转单。
7. 已出库：可上传 BOL/POD，并对未出账的已计费单据调整费用。

### 3.2 换标扫描（出库 → 换标）

1. 打开换标，页内 Tab 为「产品换标」「箱换标」。
2. 选打印方式（正文：产品标默认批量打印，也可改成单个打印；箱标默认整组文件一次打出，也可按页数自定义）。
3. 先扫出库单号，定位本单待换标的产品或箱子。
4. 再扫旧标。产品标可扫 SKU、产品条码、FNSKU，或预报时填的自定义条码。箱标扫箱类型号或自定义箱条码。
5. 系统按打印方式出新标。也可手动「打印新标文件」（卖家上传的文件）或「打印系统条码」（系统生成的条码）。
6. 回到备货中转待出库，编辑换标服务，填实际换标数量。允许先出库，但会提醒填写。计费：填了实际数量用实际数量，没填用卖家预报数量。

### 3.3 复核/验货（一件代发波次，菜单名即「复核/验货」）

1. 出库 → 复核/验货。首次使用要点安装打印控件。
2. Tab：一单一件 / 一单多件。
3. 右下角齿轮打开「复核设置」（跟账号走，换账号可能不同）。
4. 一单一件：扫波次单号，再扫 SKU。一单多件：扫出库单号 / 物流跟踪号 / 格子号，再扫条码。
5. 若开启扫描包材：扫包材编码，可多个包材或同一包材扫多次；OMS 若绑了推荐包材，会预填在包材编码框。勾选「保持」后沿用上一次包材。
6. 称重：手动输入，或自动计算（SKU 的 WMS 重量 + 包材重量）。
7. 设置开启时：复核完打面单；称重完单据变已出库。

### 3.4 包裹复核（与复核/验货二选一）

1. 出库 → 包裹复核。扫波次单号和条码。
2. 只处理待复核的出库单，且波次须已拣货、未出库。
3. 同一波次若已在复核/验货做过，不能再做包裹复核。正文提示语即此。
4. 进度按订单、包裹、产品三层展示。

## 5. 状态与 Tab（如有）

| **状态/Tab** | **含义（观察）** |
|---|---|
| 备货中转 · 待处理 | 看单并提交拣货 |
| 备货中转 · 待拣货 | 打印拣货单并回写拣货数量 |
| 备货中转 · 待出库 | 换标、按产品装箱、托盘、附件、面单、确认出库。PDA 复核出库也要求这一状态 |
| 备货中转 · 已出库 | 回传签收附件、调整未出账费用 |
| 备货中转 · 异常 / 已取消 | 列表 Tab。标记异常后先入异常件；确认异常后单据变异常，需客户在 OMS 再确认并取消 |

| 复核验货 · 一单一件 / 一单多件 | 波次品种类型，扫错类型会提示 |
| 一件代发侧待复核 | 包裹复核只接受这一状态的出库单。备货中转列表配图里没有「待复核」这一 Tab |

截单（帮助正文，备货中转）：待处理时 OMS 截单可直接取消；待拣货或待出库时 WMS 单号前出现橙色感叹号，仓库在截单模块选「回库上架」（取消并释放锁定库存）或「标记失败」（继续出库）。已出库不能取消。

## 6. 边界与提示（仅文案级）

* 汇总拣货单要求拣货方式一致（都是按产品，或都是按箱）。
* 换标打印数量刷新不归零。
* 不填实际换标数量也可以出库，但会提醒；计费回落到预报数量。
* 按产品出库未填装箱明细就不能填托盘明细。
* PDA 复核出库不允许超额。
* 复核验货与包裹复核对同一波次二选一。
* 序列号 SKU 不走「扫描后自动复核相同 SKU」。序列号本身可以在复核验货里直接扫描完成复核（正文名词解释）。
* 调整数量出库要先在 WMS 设置勾选，再在待出库「调整出库数量」。回库填回库数量，加出库填库位和数量。这部分费用正文说要在业务费用里手工调，系统不自动计费。
* 扫描波次号的失败文案（复核验货）：请扫描正确的单号；该波次号非一单一件。包裹复核：仅支持已拣货且未出库的波次；已在复核/验货做过则不能包裹复核。
